# NITCbase

A mini Relational Database Management System built from scratch in C++ as a course project for **Database Systems and Design Lab** at **NIT Calicut**.

The implementation follows the NITCbase specification — an eight-layer RDBMS design covering disk I/O, buffer management, caching, B+ Tree indexing, and a SQL-like command interface.
